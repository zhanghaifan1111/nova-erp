# Nova ERP · 智能企业管理平台

一套开箱即用的企业进销存管理系统，前后端分离架构，数据本地持久化。

> **线上地址（Render 免费版）**：https://nova-erp-6mdl.onrender.com
> 免费实例 15 分钟无访问会休眠，首次打开需等约 50 秒冷启动，属正常现象。

## 功能特性

- **经营总览**：核心 KPI、销售趋势、订单状态分布、分类销售、库存 TOP、库存预警、最近订单
- **商品管理**：SKU 档案、分类、成本价/销售价、库存与安全库存，完整增删改查
- **库存管理**：库存台账、出入库操作、流水追踪、低库存预警
- **销售订单**：客户销售订单、商品明细、状态跟踪、新建订单
- **采购订单**：供应商采购订单、到货付款状态、新建订单
- **客户 / 供应商管理**：档案分级、联系方式、合作状态
- **财务报表**：收支毛利统计、12 个月趋势、收支结构、资金流水
- **深色 / 浅色主题**一键切换，响应式布局

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 18 + TypeScript + Vite 6 + Ant Design 5 + ECharts |
| 后端 | Node.js + Express |
| 存储 | JSON 文件本地持久化（零数据库依赖） |

## 快速启动

需要 Node.js 18+。

```bash
# 1. 安装依赖
npm install

# 2. 开发模式（前后端同时启动）
npm run dev
# 前端 http://localhost:5173  后端 http://localhost:3001
```

浏览器打开 **http://localhost:5173** 即可使用。

生产部署：

```bash
npm run build   # 构建前端到 dist/
npm start       # Express 托管静态文件 + API，访问 http://localhost:3001
```

## 数据说明

首次启动会在 `data/db.json` 自动生成一套演示数据（12 个商品、8 个客户、5 个供应商、46 张销售订单、24 张采购订单及库存流水），所有操作实时写回该文件。删除该文件后重启即可重置为初始演示数据。
