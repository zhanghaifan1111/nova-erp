# 周桂祥的ERP · 智能企业管理平台

一套开箱即用的企业进销存管理系统，前后端分离架构，数据本地持久化。

> **线上地址（Render 免费版）**：https://nova-erp-6mdl.onrender.com
> 免费实例 15 分钟无访问会休眠，首次打开需等约 50 秒冷启动，属正常现象。

## 功能特性

- **经营总览**：核心 KPI、销售趋势、订单状态分布、分类销售、库存 TOP、库存预警、最近订单
- **商品管理**：SKU 档案、分类、成本价/销售价、库存与安全库存，完整增删改查
- **库存管理**：库存台账、出入库操作、流水追踪、低库存预警
- **销售订单**：客户销售订单、商品明细、状态跟踪、新建订单
- **采购订单**：供应商采购订单、到货付款状态、新建订单
- **客户 / 供应商管理**：档案分级、联系方式、合作状态
- **财务报表**：收支毛利统计、12 个月趋势、收支结构、资金流水
- **店铺管理**：多平台店铺（Shopee/Lazada/Amazon/TikTok/Temu 等）、站点、佣金率
- **仓库管理**：自营仓/第三方仓/海外仓档案、库存调拨
- **物流渠道 + 运费模板**：渠道时效价格、首重续重规则、包邮门槛
- **打单发货**：发货单、运单号、发货状态、一键标记发货
- **利润核算**：逐单净利润（收入−采购成本−运费−平台佣金−其他费用）、成本构成分析
- **定价计算器**：按成本/运费/佣金率/目标利润率反推建议售价
- **商品采集箱**：粘贴真实商品链接批量采集、去重、一键刊登到店铺
- **刊登管理**：采集商品刊登记录、平台商品ID、刊登状态跟踪
- **多平台订单同步**：平台订单 JSON 导入（自动去重）、一键转销售订单、同步日志、同步配置
- **客户消息聚合**：多店铺消息收件箱、未读统计、快捷回复模板、回复状态追踪
- **API 对接 · 订单推送**：配置对方系统接收地址（支持 Bearer/API Key/HMAC-SHA256 鉴权）、单条/批量推送订单 JSON、测试连接、推送日志、失败重试、报文预览与对接文档
- **箱唛 · 面单打印**：从订单一键生成箱唛（每 SKU 一箱、自动编号）和快递面单（寄收件人/运单号/商品明细），Code128 条码 + 二维码，打印模板可配置，浏览器直连标签打印机
- **进销存闭环**：采购入库（确认即增库存）、库存盘点（账面/实盘差异自动调整）、销售退货（确认即回补库存），全程写库存流水
- **数据导入导出**：CSV 导入商品/客户（自动去重）、10 类业务数据一键导出（UTF-8 BOM，Excel 中文不乱码）
- **登录与权限**：管理员与客户账号、客户数据隔离、客户只读
- **深色 / 浅色主题**一键切换，响应式布局，侧边栏分组导航

> 说明：商品采集与订单同步处理的是**用户自己提供的真实链接/订单数据**，不会生成虚构数据。Shopee/Amazon 等平台的官方自动拉取需要各平台开放平台的 API 授权（App Key/Token），这部分需用户在平台方申请后接入。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 18 + TypeScript + Vite 6 + Ant Design 5 + ECharts |
| 后端 | Node.js + Express |
| 存储 | JSON 文件本地持久化（零数据库依赖） |

## 快速启动

需要 Node.js 18+。

```bash
# 1. 安装依赖
npm install

# 2. 开发模式（前后端同时启动）
npm run dev
# 前端 http://localhost:5173  后端 http://localhost:3001
```

浏览器打开 **http://localhost:5173** 即可使用。

生产部署：

```bash
npm run build   # 构建前端到 dist/
npm start       # Express 托管静态文件 + API，访问 http://localhost:3001
```

## 数据说明

首次启动会在 `data/db.json` 自动生成一套演示数据（12 个商品、8 个客户、5 个供应商、46 张销售订单、24 张采购订单及库存流水），所有操作实时写回该文件。删除该文件后重启即可重置为初始演示数据。
